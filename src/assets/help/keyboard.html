Раскладки клавиатуры

Программа позволяет вводить текст на греческом, латинском и русском языках независимо от того, какая раскладка выбрана в операционной системе. Для этого в области ввода предусмотрены три кнопки: Gr (греческая), La (латинская) и Ru (русская). Активная раскладка выделена цветом.

Когда выбрана одна из этих раскладок, программа перехватывает нажатия клавиш и преобразует их в символы соответствующего языка. Раскладка операционной системы при этом не имеет значения — можно набирать греческий текст, не переключая язык в операционной системе.

Кнопки Gr / La / Ru задают только язык ввода. Язык поиска программа определяет автоматически по первой букве введённого слова. Например, если ввести ἀγγελία в любой раскладке, поиск будет вестись по греческим словарям, а если известие — по русским переводам.

Раскладка ввода соответствует стандартной раскладке соответствующего языка.

Поиск

Инкрементный поиск. Начните набирать слово в поле ввода. По мере ввода в основной области появляется список ключевых слов из словарей, начинающихся с введённых символов. Язык ввода определяется кнопками Gr / La / Ru. Двойной щелчок по ключевому слову в списке открывает словарную статью.

Точный поиск. Двойной щелчок по слову или нажатие Enter на слове в поле ввода запускает точный поиск — по полному ключу с учётом диакритики. Если ключ найден, открывается словарная статья. Если точного совпадения нет, программа автоматически переходит к приближённому поиску.

Приближённый поиск. Выполняется без учёта регистра и диакритики. Слово приводится к канонической форме (например, καρπόω → καρποω), ищутся все ключи с такой же канонической формой. Результат — список ключевых слов, который можно листать. Список полезен, когда написание слова вызывает сомнения.

Полнотекстовый поиск. Выполняется по всему тексту словарных статей — включая переводы, примеры и цитаты. Для запуска введите слово и нажмите Shift+Enter. Для русских слов достаточно Enter — программа автоматически определяет русское слово и запускает полнотекстовый поиск. Результат — таблица с тремя колонками: ключевое слово статьи, название словаря и контекст, в котором найдено слово. Поиск выполняется без учёта регистра и диакритики. Двойной щелчок по ключевому слову в таблице открывает соответствующую словарную статью.
